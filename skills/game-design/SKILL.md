# Skill: Game Design

Use this skill for core loops, run structure, items, synergies, bosses, perks, encounters, progression and feature proposals.

## Objective
Create high replayability from a compact content budget. Every new system must either deepen decisions, improve retention, strengthen the fantasy, or improve commercial viability.

## Core rules
- Target a 32–42 minute six-world base campaign, with a first boss at roughly 3–5 minutes; campaign + Loop 2 targets 55–75 minutes and deeper Loop 3 sessions can reach 80+ minutes.
- Keep meaningful decisions/payoffs frequent: roughly every 20–60 seconds even inside a long session.
- Prefer combinatorial depth: tags × placement × shapes × recipes × perks × boss rules.
- Avoid content treadmills that require hundreds of bespoke levels.
- Every item needs at least one obvious use and ideally one discovery/synergy use.
- Every boss must change how the player arranges or values the backpack; a larger HP bar alone is not a boss mechanic.
- Counterplay must exist. Boss disruption can be surprising, not arbitrary.
- Randomness creates dilemmas, not unwinnable states.
- Builds should support pivots; do not lock the player into a class before they understand the run.
- Do not extend session length with HP sponges alone. Added time must come from meaningful build decisions, events, fusions, mutations and progression.

## Run structure
Default cadence: shop/reward → arrange backpack → combat → reward/event → repeat → boss → perk/world mutation. The base campaign contains six worlds / 18 encounters and exposes all six authored boss families. After the campaign, the player may cash out or commit the same build to a four-world / 12-encounter Corrupted Loop; repeated loops stay compact so the longer base campaign does not multiply every deep cycle.

Long-run orientation matters: the player should be able to identify the current world, completed campaign worlds, encounter position and next safe-exit boundary without opening a separate screen.

## Content-efficiency test
Before adding content, ask: “How many existing systems does this interact with?” Prefer an item that creates 8 new interactions over an isolated item with one bespoke effect.

## Boss checklist
A boss needs:
- a readable rule-changing gimmick;
- telegraphing;
- at least two viable counter-strategies;
- an escalating phase or modifier;
- a clear reward breakpoint;
- no mechanic that permanently destroys a run without warning.

## Retention layers
Use layered goals: immediate fight outcome → world completion → run build → recipe discovery → collection → mastery/endless/daily challenge.

## Scope veto
Reject proposals that imply large bespoke maps, real-time multiplayer, cinematic campaigns or large server systems unless explicitly promoted in `ROADMAP.md`.
